Carnet de vol public

Un mini-site statique (vols, carte, passagers, passeports, cartes postales) à publier sur GitHub Pages. Rien ne pointe vers ton PC : ce sont juste des fichiers. Les villes des viewers ne sont jamais publiées, et un viewer peut se retirer avec !passeport cacher.

Publication automatique sur GitHub Pages
Créer le jeton GitHub (2 min)
  1. Crée le dépôt public du carnet sur GitHub (par exemple carnet). Il peut être vide.
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → « Generate new token ».
  3. Repository access : Only select repositories → choisis uniquement le dépôt du carnet.
  4. Permissions → Repository permissions : Contents : Read and write. Ajoute Pages : Read and write si tu veux que FlightBrief active le site tout seul.
  5. Copie le jeton (il commence par github_pat_) et colle-le ici. Il est chiffré sur ton PC et ne donne accès à aucun autre dépôt.
Comment le mettre en ligne à la main (GitHub Pages)
  1. Sur GitHub, crée un dépôt public, par exemple carnet.
  2. « Add file » → « Upload files » : glisse tout le contenu du dossier généré (pas le dossier lui-même), puis « Commit ».
  3. Settings → Pages → Branch : main / (root) → Save. Le site est en ligne à https://ton-compte.github.io/carnet en une minute.
  4. Après de nouveaux vols : régénère, puis ré-uploade les fichiers (GitHub remplace les anciens).

À propos

FlightBrief —

📱 Application mobile

Ton logbook, tes carrières, tes tours et ton hangar sur ton téléphone, même hors ligne. L'appli garde une copie des données sur le téléphone : tu la mets à jour d'un appui sur « Synchroniser » quand tu es sur le même Wi-Fi que ce PC (FlightBrief ouvert). Rien ne passe par Internet.

Activer l'accès depuis le téléphone
  1. Scanne le QR code avec l'appareil photo du téléphone (sur iPhone, ouvre le lien dans Safari).
  2. La page qui s'ouvre te guide pour approuver le certificat de ce PC — à faire une seule fois. Il est limité à FlightBrief sur ton réseau local.
  3. Ouvre l'appli puis ajoute-la à l'écran d'accueil (iPhone : Partager → « Sur l'écran d'accueil » · Android : menu ⋮ → « Installer l'application »).
  4. Ensuite, l'icône s'ouvre partout, sans PC ni Wi-Fi. Touche Synchroniser de retour chez toi pour la mettre à jour.
Au premier lancement, Windows peut demander d'autoriser FlightBrief sur le réseau : accepte pour les réseaux privés. Si plusieurs adresses sont proposées, choisis celle de ta box (souvent 192.168.x.x).
